## 2. How to work

These are Grey's standing rules.

- **Branches.** Develop on a feature branch, then merge into `main` in `C:\Projects\ZAENIA`.
- **Record every change** in `docs/architecture/ZAENIA_Master_Build_Plan.md`: bump the version and add a section.
- **Testing:**
  - Python: `.venv\Scripts\python.exe -m unittest` over every `*_test.py` in `core` and `scripts`. The last run was 824 OK, 14 skipped.
  - Desktop: `npx tsc --noEmit -p .` and `node scripts/*.test.cjs` in `desktop`.
- **Build and install:**
  - Build, in `desktop`: `npm run build`, then `npm run build:web` (the browser version must update too), then `npm run tauri build -- --no-bundle`.
  - Install: `scripts\restart_zaenia_server.ps1`, then `scripts\install_start_menu.ps1`, then start `%LOCALAPPDATA%\Programs\ZAENIA\ZAENIA.exe`.
  - Check: `http://127.0.0.1:8766/health` should return 200.
- **Look tokens.** Every new screen uses the tokens in `desktop/src/styles/look-styles.css` (`--zx-panel`, `--zx-line`, `--zx-radius`, `--zx-gap`, `--zx-text`, `--zx-muted` and the rest, plus the `.zx-card`, `.zx-inset` and `.zx-title` classes). That way the window style, per-tab colour, density, corners, panel solidity and motion all apply.
- **File names.** `.gitignore` drops any file named `*token*`.
- **Paused animations.** When the window isn't focused, `.zaenia-app--background` pauses CSS animations. Never animate `opacity` from 0, or content stays invisible while paused; animate `transform` only.
- **Safety:**
  - Don't spoof user agents or bypass bot checks.
  - Don't read secret keys such as FDC_API_KEY.
  - Passkey-gated commands are Grey's to run.
  - ZAE never claims human feelings. Grey makes the decisions.
- **Pronouns.** Use they/them for Grey. Ask Grey questions as short multiple-choice options.
