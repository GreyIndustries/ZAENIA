## Importing into Zae

Open **Assistant → Learning library → Learn from downloaded text**.
Choose one topic's Markdown file and select **Learn this text**. Repeat for
the desired topics. For one import, choose **ZAE_LEARNING_PACK_ALL.md**, which
contains all fifteen guides. Import the combined file OR the individual files
to avoid duplicate excerpts. The ZIP is for packaging; extract it before selecting
a text file. Nothing in this folder has been automatically imported into the app.

Importing a guide makes its text searchable. It does not automatically crawl
its links, retrieve PDFs, train model weights, add an audio emotion detector,
authorize actions or change Zae's identity. The topic guides are reference data,
and their suggested behaviors are proposals, not system instructions.

## Using the sources well

For Army or health questions, check the current official text and applicable
circumstances. The Army guide is deliberately a research guide, not a substitute
for the full governing publications. For science, select a field and add actual
textbook chapters or research sources instead of trying to download “all science.”

For fiction, identify the work and continuity; book, film, game and fan interpretation
are distinct. For music, use legal listening links and distinguish interpretation
from artist intent. No copyrighted novels, comics, scripts, recordings or lyrics
are reproduced in this pack. Public availability of a link is not a redistribution license.

Some sources require a browser, offer PDFs, use scripts, or limit automated access.
A link in these files does not guarantee Zae's current webpage reader can import
the complete source. Its text importer supports TXT/Markdown; its separate
Documents feature supports approved local document folders.

## A useful first check

After importing, ask: “Using my learning library, explain the difference between
voice tone and a transcript, and name the sources.” Then ask a question specific
to another imported topic. Check that the answer retrieves the right excerpt
and does not claim a linked source was read unless it was actually obtained.
