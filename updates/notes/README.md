# Release-note fragments
One JSON file per feature branch: {"branch":"...","part":"ui|system|tab:<id>","notes":[{"kind":"added|changed|fixed|removed|performance|security|limitations","title":"...","description":"..."}]}.
Use limitations (the updater schema), not known-limitation. The release owner combines fragments and archives them under released/<version>/ after shipping. No artifacts or private data belong here.
